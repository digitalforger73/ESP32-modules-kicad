이 프로젝트는 KiCad 10에서 작성되었습니다.

1. "ESP32 Board Package Installation" 문서를 참고하여 ESP32 보드 패키지를 설치합니다.

2. KiCad에 User 심볼 라이브러리와 User 풋프린트 라이브러리를 생성합니다.
일반적인 위치:
{사용자 홈 디렉터리}/Documents/KiCad/10.0/symbols
{사용자 홈 디렉터리}/Documents/KiCad/10.0/footprints

3. components 디렉터리의 모든 압축 파일을 원하는 위치에 풀고, 포함된 심볼(Symbol) 및 풋프린트(Footprint) 라이브러리를 KiCad의 User 라이브러리들에 추가합니다.

4. 회로도 편집기(Schematic Editor)를 엽니다.
부품이 누락되어 있다면 심볼 라이브러리에서 해당 부품을 추가합니다. 또한 부품을 선택한 후 E 키를 눌러 부품 속성(Properties) 창을 엽니다. Footprint 항목에서 User 풋프린트 라이브러리를 선택한 뒤, 새로 추가한 부품에 해당하는 풋프린트를 지정합니다.

5. PCB 편집기(PCB Editor)로 전환한 후 "Update PCB from Schematic" 아이콘을 클릭하여 PCB를 회로도와 동기화합니다. 이후 새로 추가된 풋프린트에 맞게 배선을 다시 연결(Reroute)합니다.

4. 부품이 누락되었거나 원하는 부품으로 교체하려는 경우에는 "How to Replace a Part" 문서를 참고하십시오.
