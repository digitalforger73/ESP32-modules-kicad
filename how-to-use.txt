This project is generated by KiCad version 10.

1. Install ESP board packages using "ESP32 Board Package Installation"

2. Create 'User' symbol library and 'User' footprint library in the KiCad.
(Typically at {user_home directory}/Document/KiCad/10.0/symbols and {user_home directory}/Document/KiCad/10.0/footprints)

3. Unzip all the files under components directory to a selected directory, and add their symbols and footprints to the created User libraries of KiCad. 

4. Open schematic editor window. If a part is missing, add the new part from the symbol library. Also, select the part and press 'E' key to open its properties window. Then at the footprint field, open the user footprint library and choose the new part's footprint in the user library.

5. Switch to the pcb editor window, and click 'Update the pcb from schematic' icon to update the pcb. Then reroute the new footprints.

6. Refer to "how-to-replace-a-part", if a part is missing or if you need to replace a part with your preferred one.
